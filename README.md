# Peano Calculator

This is a very slow 4-function calculator which runs entirely on church encded rationals / peano arithmetic, using nested python tuples to encode values.

Made + Shipped on the last day of Hack Club Horizons
## Installation

1. Go to the releases tab
2. Download
3. Run

## Usage

Press the buttons to input values
Press `:3` for a suprise :3
